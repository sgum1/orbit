# Orbit

A minimal, research-informed app for keeping up with friends and growing new acquaintances into friendships.

- Weekly plan of who to see in person and who to check in with, based on closeness tiers (Dunbar's layers) and friendship research
- Calendar for social plans, including repeating ones
- Birthdays, follow-ups, groups, long-distance friends, and who-reaches-out balance

**Privacy:** Orbit has no server and no account. Everything you enter is stored only on your own device (browser local storage, or the installed Home Screen app). This repository contains only the app's code.

**Install on iPhone:** open the site in Safari, tap Share, then Add to Home Screen.
